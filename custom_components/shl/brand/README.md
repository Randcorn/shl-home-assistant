# SHL brand assets

The logo and favicon SVG sources are official SHL website assets, downloaded
from:

- https://sportality.cdn.s8y.se/team-logos/shl1_shl.svg
- https://sportality.cdn.s8y.se/team-logos/shl1_shl.favicon.svg

The PNG files are rendered from those sources for Home Assistant. `logo.png`
uses the dark SHL wordmark for light backgrounds, while `dark_logo.png` keeps
the original white wordmark for dark backgrounds. The two icon PNGs use the
official circular favicon with colors inverted for dark mode.
