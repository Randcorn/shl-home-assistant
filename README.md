# SHL Home Assistant integration

Experimental Home Assistant custom integration for SHL.

This first prototype contains the API client, play-by-play goal parser,
event de-duplication model, a coordinator skeleton, sensor skeleton, and
a historical goal fixture from Skellefteå AIK–Luleå HF.

The current SHL website APIs are observed public website APIs; they are not
assumed to be a documented/stable public API.
